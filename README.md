# ShipFlow

ShipFlow 是一个面向互联网测试开发工程师求职的企业级跨境物流履约与费用结算仿真项目。项目以真实业务流程为核心，覆盖订单履约、跨境物流协同、状态流转、费用计算与结算，以及相应的接口、数据库和异步业务测试。

## 后续阶段

- 项目建模与业务流程设计
- 单模块业务实现与配套测试
- Mock 服务与异常场景建设
- 部署配置、测试报告和缺陷记录完善
- 持续补充学习笔记与项目复盘

当前已完成项目初始化、第一版业务边界、领域模型、MySQL 数据库设计、初始化脚本和 Ubuntu/MySQL 8.0 容器中的数据库验证。后端业务代码尚未开始开发。
