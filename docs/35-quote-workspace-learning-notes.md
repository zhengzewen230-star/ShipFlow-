# 报价工作台学习笔记

## 业务流程

租户商户用户提交店铺、物流渠道、目的国家与申报重量/尺寸，后端基于当时已发布的价格规则生成正式报价快照。报价创建后，金额、计费输入、规则版本和费用明细均不可由前端重新计算或修改；用户只能查询详情并校验是否仍可用于创建订单。

参与方为租户商户用户、店铺、物流渠道和平台发布的价格规则。所有报价查询都由服务端按 JWT 中的 `tenantId` 限定，前端不传递或推断其他租户范围。

## 状态与异常

报价状态为 `VALID`、`EXPIRED` 或 `CANCELLED`。校验接口还会返回是否已被订单使用；仅 `VALID`、未过期且未被使用的报价可创建订单。有效期时间由后端以 UTC 偏移时间返回，前端只展示原始服务端时间，不改变业务判断。

价格规则缺失、渠道不服务目的国家、店铺未启用或无权限等错误仍由后端决定并返回。页面仅展示真实错误消息，不以演示数据代替计算结果。

## 工作台展示原则

报价列表展示报价单号、目的国家、计费重量、金额、币种、状态与有效期。详情将完整响应分为报价信息、货物与计费重量、已应用价格规则、费用结果，并使用已有 `validateQuote` 操作展示当前可用性。

## 待确认事项

当前正式报价响应只提供店铺和渠道 ID。若商户需要在报价历史直接辨认店铺和渠道名称，需要确认是否应在报价查询契约中增加只读显示字段，或由前端在权限允许时通过现有查询接口补充名称。
