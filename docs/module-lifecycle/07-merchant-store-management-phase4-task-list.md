## P4-03 收口记录

- 店铺编辑和启停继续使用 `tenant_id + user_id + role + active sys_user_store_scope` 资源校验；未授权资源仍返回 404。
- 编辑、启停均为事务写接口，要求 `Idempotency-Key`，请求摘要绑定操作体，版本号防止并发覆盖；重复请求不重复写入，幂等键复用不同请求体返回 409。
- 停用店铺后的订单创建在服务端复核 `merchant_store.status='ACTIVE'`，停用店铺新建订单返回 `STORE-1002/422`；历史订单查询链路未改变。
- 前端仅在 `store:manage` 下显示编辑和启停，启停需二次确认，编辑不回显原始平台账号，写入期间禁用重复操作并显示真实错误 Trace ID。
