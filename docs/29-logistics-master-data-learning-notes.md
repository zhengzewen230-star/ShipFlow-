# 物流主数据管理学习笔记

- 物流商、渠道和价格规则为平台公共主数据；租户查询仍必须限定 JWT 的 `scope=TENANT`，且只读，不授予平台写权限。
- 渠道启用的前置条件是物流商启用、至少一个服务国家和至少一个已发布价格规则；租户目录再次在 SQL 中限制物流商与渠道均为 `ACTIVE`。
- 价格金额、重量与体积除数使用 `BigDecimal`；所有 API 时间字段按 UTC 处理。阶梯使用左闭右开区间 `[min_weight,max_weight)`，必须连续并以无上界的最终阶梯结束。
- 已发布规则没有更新接口。规则调整通过同一渠道创建新的 `version_no`，数据库唯一约束和服务层冲突映射共同防止重复版本。
- 创建物流商、渠道和价格规则使用 `Idempotency-Key`；所有平台写操作置于事务并写入审计日志。该模块不改报价快照、订单历史费用或仓库记录。
