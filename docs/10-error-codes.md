# ShipFlow API 错误码

错误码格式：`模块-四位数字`。HTTP 状态码表达协议层结果，错误码表达业务原因。

## 与 OpenAPI 的对应关系

`openapi/shipflow-api.yaml` 使用统一响应组件：`AuthError` 对应 401、`Forbidden` 对应 403、`NotFound` 对应 404、`Conflict` 对应 409，业务规则组件对应 422，`BadRequest` 对应 400。响应体中的 `error.code` 必须使用本文件中的错误码，响应头 `X-Trace-Id` 必须与响应体 `traceId` 一致。

核心接口必须覆盖 401、403；资源型接口必须覆盖 404；幂等、乐观锁和状态冲突必须覆盖 409；参数和业务规则校验必须覆盖 400 或 422。重复轨迹事件只通过 `TrackingEventResult.status=DUPLICATE` 表示成功，不重复推进状态或写入业务影响。

## 租户隔离和授权语义

- 未携带、格式错误、签名无效或过期的 Access Token 使用 401 和 `COMMON-1002`/`COMMON-1003`。
- 调用者已认证，但缺少访问某类功能所需权限时使用 403 和 `COMMON-1004`。
- 租户作用域资源按 `id + 当前 tenant_id + deleted=0` 查询。资源不存在、已删除或属于其他租户时统一使用 404 和 `COMMON-1006`，避免枚举其他租户资源。
- 平台管理路径不是租户资源；非平台作用域调用者访问该路径时使用 403 和 `COMMON-1004`，不使用 `TENANT-1003`。
- 已停用的租户、用户或角色由实时身份重载拒绝：当前请求若无法形成有效身份，使用 401 和 `COMMON-1002`；对已定位资源执行不允许的状态转换则使用对应模块的 422 状态错误。

## COMMON

| 错误码 | HTTP | 含义 |
|---|---:|---|
| `COMMON-1001` | 400 | 请求参数错误 |
| `COMMON-1002` | 401 | 未登录或 Token 无效 |
| `COMMON-1003` | 401 | Token 已过期 |
| `COMMON-1004` | 403 | 权限不足 |
| `COMMON-1005` | 409 | 乐观锁冲突 |
| `COMMON-1006` | 404 | 资源不存在 |
| `COMMON-1007` | 500 | 内部系统错误 |
| `COMMON-1008` | 400 | 请求体格式错误 |
| `COMMON-1009` | 409 | 幂等键与请求内容冲突 |
| `COMMON-1010` | 409 | 相同幂等请求正在处理中 |

## AUTH

| 错误码 | HTTP | 含义 |
|---|---:|---|
| `AUTH-1001` | 401 | 登录失败（用户不存在、密码/tenantCode错误、用户或租户禁用、系统账号禁止登录均使用此码） |
| `AUTH-1002` | 401 | Refresh Token 无效 |
| `AUTH-1003` | 401 | Refresh Token 已过期 |
| `AUTH-1004` | 401 | 内部身份范围不匹配；不出现在公开登录接口响应中，仅供内部流程或安全审计映射 |
| `AUTH-1005` | 403 | CSRF Cookie 与 `X-XSRF-TOKEN` 请求头缺失或不匹配 |

## TENANT

| 错误码 | HTTP | 含义 |
|---|---:|---|
| `TENANT-1001` | 409 | 租户编码已存在 |
| `TENANT-1002` | 422 | 租户状态不允许该操作 |
| `TENANT-1003` | 422 | 租户状态不允许修改基础信息或创建初始管理员；跨租户资源不使用此码，统一 `COMMON-1006` |

## USER

| `USER-1003` | 403 | 不能管理平台用户或当前角色不允许管理的用户；跨租户资源查询仍统一404 |

## ROLE

| 错误码 | HTTP | 含义 |
|---|---:|---|

## 第二阶段权限码基线

第二阶段接口使用以下权限码：`tenant:create`、`tenant:read`、`tenant:manage`、`user:manage`、`store:read`、`store:manage`、`role:read`、`role:manage`、`permission:read`。当前 `init_data.sql` 只含其中一部分；在实现前必须通过受控迁移和初始化数据补齐权限字典及角色绑定，不能用角色名称字符串替代权限判断。

## QUOTE

| 错误码 | HTTP | 含义 |
|---|---:|---|
| `QUOTE-1001` | 422 | 报价参数、重量尺寸或阶梯计费输入非法 |
| `QUOTE-1002` | 422 | 当前时点不存在生效且已发布的价格规则版本 |
| `QUOTE-1003` | 422 | 报价已过期 |
| `QUOTE-1004` | 409 | 报价已被订单使用 |
| `QUOTE-1005` | 409 | 报价版本冲突 |
| `QUOTE-1006` | 422 | 店铺未启用，或当前渠道未启用/不服务目的国家 |

## ORDER

| 错误码 | HTTP | 含义 |
|---|---:|---|
| `ORDER-1001` | 409 | 非法订单状态跳转 |
| `ORDER-1002` | 409 | 订单专属幂等冲突 |
| `ORDER-1003` | 422 | 报价状态无效、已取消，或收件国家与报价目的国不一致；跨租户报价统一 `COMMON-1006` |
