# 第三阶段基线与任务清单学习笔记

## 本子阶段完成内容

- 复核了现有 operations、warehouse overview、订单状态机、物流 `LABEL_READY`、费用确认、异常/索赔、账单对账、前端路由和 OpenAPI。
- 确认旧 operations API 只有租户级订单聚合和部分待办，尚不能承载时间窗口、店铺授权、最近订单、风险提醒和统一快照。
- 建立了第三阶段子阶段边界，先做文档基线，再逐步做后端概览契约、前端工作台、列表跳转、刷新时间范围和最终验收。

## 关键经验

运营概览不能让前端把多个独立接口的数字拼成“统一统计”。统一快照需要后端固定时间窗口、刷新时间和资源范围，并明确每个指标对应的列表筛选条件。旧查询如果只按 `tenant_id` 汇总，即使页面有店铺选择器，也不能满足商家业务员的 `store_id` 隔离规则。

## 验证边界

本子阶段仅修改中文生命周期文档和学习笔记，没有修改 Java、Vue、SQL、迁移或 OpenAPI，没有执行 Flyway、数据库写入、顺丰调用、Git 提交或推送。后续 P3-02 开始代码修改前，必须重新检查当前工作区和基线文档。
