# 身份与功能入口学习笔记

## 业务流程

登录成功后，前端保存内存 Access Token，再请求 `GET /api/v1/users/me`。后端根据当前用户、租户和有效角色实时加载角色码与权限码；前端完成身份初始化后才生成菜单并执行路由判断。

角色码用于显示“平台超级管理员、租户管理员、商户业务人员、财务人员、仓库操作员、客服/异常专员”等身份。实际授权始终使用权限码，避免通过用户名或角色名称绕过细粒度授权。

## 规则与异常路径

- 平台用户只能进入平台作用域功能；租户用户只能进入本租户功能，业务数据仍由后端 `tenant_id` 隔离。
- 访客可访问预估和入驻申请，但不能创建正式报价或订单。
- 已登录租户用户访问访客报价页时，只有具备 `quote:create` 才进入正式报价；财务、仓库、客服等用户返回控制台首页。
- 权限初始化未完成时路由守卫等待同一恢复 Promise，不提前判定 403。
- 物流服务商轨迹回调使用 HMAC 服务端认证，不是浏览器用户功能。
