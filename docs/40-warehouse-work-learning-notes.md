# 仓库作业工作台学习记录

## 2026-08-16

- 仓库列表必须只展示后端投影字段，状态 Tab 不能用前端常量伪造不存在的供应商状态；没有 `V013` 持久化表时，待打单/贴标应明确标记契约缺口。
- 顺丰调用必须保持在后端适配层，页面只提交操作意图和幂等键；官方签名算法、报文和凭据不完整时，服务端应在发出 HTTP 请求前返回配置错误。
- 仓库入库、复称、出库使用同一租户范围、乐观锁版本和幂等记录。前端操作成功后重新读取详情，避免把旧版本继续用于下一次状态变更。
- Dashboard 待贴标统计必须与订单列表使用同一投影口径：`READY_FOR_OUTBOUND` 且供应商生命周期不是 `LABEL_READY` 的订单计入待贴标，使用 `LEFT JOIN` 兼容尚未生成供应商记录的订单。
- 订单列表与仓库概览的 `chargeableWeight` 按数据库克值转换为千克并保留两位；报价字段仍按既有 kg 契约展示，不能复用克转千克逻辑。
