# 列表与筛选控件统一规范

## 目标

让不同业务页面的 `data-table`、排序表头、筛选输入框、下拉框和查询操作共享同一套企业控制台规范，同时不改变任何 API 参数或业务值。

## 规则

- 表头固定 42px，高度、字体、背景、边框和垂直对齐由公共样式统一维护。
- 排序表头是透明的文本型按钮，带统一 `↕` 提示与键盘焦点；不能继承浏览器默认灰色按钮背景。
- 文本列默认左对齐；状态徽章和末尾操作列在表头及内容中居中，避免视觉漂移。
- 筛选输入框保持左对齐；筛选下拉框的当前值使用 `text-align-last: center` 居中显示，并统一为 38px 高。
- 移动端允许表格在 `.data-table-wrap` 内滚动，页面主容器不能产生横向溢出。

## 边界

这些规则只影响 `.app-content` 的展示层。下拉框 `value`、查询参数、状态编码、权限和后端数据均不改变。
