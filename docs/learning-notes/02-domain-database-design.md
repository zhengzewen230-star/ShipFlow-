# 阶段 2 学习笔记：领域模型与数据库设计

## 本阶段内容

- 将租户、报价、订单、单包裹、复称、轨迹、账单和对账业务映射为领域对象。
- 使用报价快照隔离历史价格与后续渠道调价。
- 使用 `idempotency_key` 和数据库唯一索引控制重复下单。
- 使用物流商、物流单号和事件 ID处理重复轨迹回调。
- 使用账单文件 Hash 和物流商账单明细号防止重复导入。
- 区分技术乐观锁 `version` 与业务价格版本 `version_no`。

## 关键理解

报价阶段的重量是商家申报重量；仓库复称后的重量是仓库实际重量。两类数据分别服务于报价快照和履约复核，不能互相覆盖。第一版一个订单只能有一个包裹，但一个包裹可以有多个商品和多次复称。
