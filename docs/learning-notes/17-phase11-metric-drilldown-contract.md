# 第十一阶段：首页指标与下钻同口径

## 模块范围

首页八项指标通过同一个 MyBatis `metricDrilldownFacts` 事实行片段计算总数和分页明细。服务端以租户、调用者店铺授权、UTC 时间窗、指标键作为唯一查询上下文；前端仅展示该专用下钻接口返回的 `total` 与明细，不再把普通业务列表伪装成指标明细。

## 业务规则

- `TODAY`、最近 7/30 天先按 `Asia/Shanghai` 自然日计算，再用 UTC `[from,to)` 查询。
- 订单型指标按订单去重；轨迹异常按关联订单分组；待财务处理是费用调整、错误账单批次、非零差异对账和待财务异常的事实任务联合列表。
- `storeId` 只能收窄调用者已授权的 ACTIVE 店铺。非法指标为 400，越权店铺为 403。
- 指标数和分页 `total` 都调用相同 SQL 事实行片段，前端不计算、不过滤、不补数。
