# 第十一阶段学习笔记：右侧 ERP 登录表单

## 范围

只优化登录页右侧 `login-panel` 和 `login-form` 的字号、字段、焦点和按钮状态；不改动左侧品牌区、认证请求、路由或权限逻辑。

## 规范

- 表单宽度上限为 440px，字段高度 46px，标签与输入框间距 7px，字段组间距 20px。
- 标题使用 32–36px、700 字重；欢迎文字 14px 青色；标签 14px；辅助文本 12–13px；输入和按钮文字 15px。
- 聚焦、禁用、错误、浏览器自动填充与提交中状态都通过边框、阴影、文字或光标反馈，不仅依赖颜色。
- 密码显示按钮维持语义化按钮及 `aria-label`，并在输入框垂直中心对齐。
