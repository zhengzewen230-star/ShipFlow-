# 第十阶段：账单导入与对账闭环

## 业务流程

租户财务人员上传供应商 CSV 后，后端逐行解析并以租户内订单和真实订单费用进行匹配。成功行生成账单明细；重复、格式错误、订单不匹配和币种不匹配行保存为可查询错误明细。系统费用与供应商费用相等时由后端自动完成对账，存在差异时进入人工处理，财务人员可确认、驳回或补充说明。

## 关键规则

- 金额只来自后端订单快照和供应商 CSV，前端人工动作不接收金额字段。
- 批次分别统计成功、错误和重复行；原始行仅保存服务端脱敏结果。
- 写操作使用租户范围、权限、事务、`Idempotency-Key`、version 乐观锁、审计日志和 Trace ID。
- 对账历史以 UTC 入库，API 返回带偏移时间；列表按时间与 ID 稳定排序。
- V023 只增加字段、约束、索引和历史表，不改写或删除历史业务数据。

## 回归重点

后续修改需要同时验证批次数量恒等关系、重复内容幂等、错误明细脱敏、零差异自动完成、非零差异状态机、同键异参冲突、旧 version 冲突、跨租户不可见以及 OpenAPI 与 DTO 字段一致性。
