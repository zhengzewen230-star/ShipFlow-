# 店铺详情只读能力学习笔记

## 结论

店铺详情不能把列表对象直接复用到页面。列表对象包含平台账号字段时，详情接口必须重新定义输出 DTO，并在服务端完成脱敏；不能依赖前端隐藏字段。

## 权限与聚合顺序

先用 `tenant_id + user_id + role + active sys_user_store_scope` 查询可见店铺，失败立即返回统一 404；只有通过资源归属校验后，才查询 `shipment_order` 历史数量和 `audit_log` 摘要，避免跨租户或跨店铺聚合泄露资源存在性。

## 结构缺口处理

当前 `merchant_store` 没有国家/地区、默认发货地址、默认物流渠道字段或可靠关联。详情响应使用 `null + unavailableFields` 表达后端暂不支持，前端显示中文契约缺口提示；待后续阶段确认结构和迁移后再实现。

## 时间与测试

审计时间按数据库 UTC 读取，前端按 Asia/Shanghai 展示。P4-02 使用 JDK 21.0.11 完成后端 17/17 定向测试，前端 72/72 单元测试和生产构建通过；没有执行数据库写入、Flyway 或生产接口调用。
